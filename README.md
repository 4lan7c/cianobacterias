## Cianobactérias é um script que cria scripts

Feito a partir dos estudos do "Pequeno Manual do Programador GNU/BASH" do Blau Araujo

Só é requerido um único parâmetro como nome do script

Ex: cn nomedoseuscript

O nome do script vem da leitura do livro "O Oráculo da Noite - Sidarta Ribeiro".

As cianobactérias foram responsáveis pela projeção de oxigênio na atmosfera terrestre, portanto deram início a tudo.
Esse script é meio isso, por onde eu sempre começo.
